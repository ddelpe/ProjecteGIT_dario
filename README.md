Instal·lació:
1- Primer obrim la carpeta del nostre projecte a la terminal i fem la comanda git init
2- Despres creem un nou repositori en Github
4- En Github desktop he clonat en nostre treball a una carpeta buida
5- Despres he fet un commit i un push per pujar-ho tot a Github

Ús:
1- Per fer cambis i que apareguin al repositori simplement fem els combis necesaris 
2- Per pujar-ho anem al github desktop i fem un commit amb un titol i explicant els canvis fets
3- Donarl-hi a push i ja s'haura pujat al repositori

- joc de pokemons en solitari
- Desenvolupat amb Vue.js
